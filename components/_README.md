# 🧩 components/ — Reusable UI Building Blocks

This folder contains React components that are **shared across multiple pages**.

```
components/
├── ui/                   ← shadcn/ui base components (don't edit these)
│                            Includes: Button, Card, Dialog, Input, etc.
├── emails/
│   └── VideoReadyEmail.tsx ← Email template sent when a video is done
├── billing/
│   └── PricingTable.tsx  ← The pricing plans table shown on /billing
├── Sidebar.tsx           ← Left-side navigation menu
├── UpgradeModal.tsx      ← Popup that appears when a user hits their plan limit
└── WizardFooter.tsx      ← "Back" / "Next" buttons used at the bottom of the wizard
```

## 👉 How to edit

- **Add a link to the sidebar?** → Edit `Sidebar.tsx`
- **Change the upgrade popup message?** → Edit `UpgradeModal.tsx`
- **Change the pricing display?** → Edit `billing/PricingTable.tsx`
- **Change what the "video ready" email looks like?** → Edit `emails/VideoReadyEmail.tsx`
- **Need a new button/input/etc.?** → Check `ui/` first before building one from scratch

> ⚠️ Do **not** edit files inside `ui/` — these are auto-generated by shadcn/ui.
